📘 Panduan HABI STUDIO CODING .ZIP

🚀 Deploy Single File

Tempel kode HTML/CSS/JS dari chat AI. Tool otomatis membungkus dengan struktur HTML jika belum lengkap. Klik Deploy Single File → langsung terupload ke repo sebagai index.html.

📦 Upload ZIP (Banyak File)

Kompres folder project menjadi ZIP (pakai ZArchiver), lalu upload. Semua file akan diekstrak dan diupload dengan struktur yang sama persis.

✏️ Editor Single File

Edit file tertentu di repo langsung dari HP. Gunakan fitur cari & ganti teks, cek error JavaScript/JSON/HTML, lalu upload dengan konfirmasi HABI STUDIO NOTE.

⚙️ Manajemen Repository (Baru!)

Fitur lengkap untuk mengelola repo tanpa buka GitHub manual:

  • Hapus Semua File – mengosongkan repo dalam satu klik.
  • Cari & Kelola File – cari file berdasarkan nama, download dulu, lalu hapus.
  • Hapus Folder – hapus folder beserta semua file di dalamnya.
  • Hapus Repository – hapus repo permanen (hati-hati!).

Catatan: Pastikan token GitHub memiliki izin repo dan delete_repo.
