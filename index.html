📘 Panduan HABI STUDIO CODING .ZIP

📄 Single File Upload (ke folder pilihan)

1. Isi username, repo, token. 2. Klik Muat Struktur untuk mengambil daftar folder. 3. Pilih folder tujuan. 4. Masukkan nama file. 5. Tempel kode. 6. Klik Upload File.

📦 Upload ZIP

Kompres folder proyek jadi ZIP, pilih file, klik upload. Semua file/folder di-zip akan di-upload dengan struktur yang sama.

✏️ Editor File

1. Muat struktur. 2. Pilih file dari dropdown. 3. Klik Muat File. 4. Edit kode. 5. Klik Simpan & Upload.

⚙️ Manajemen Repo

Klik Muat Struktur Repo untuk melihat semua file & folder. Di sini kamu bisa:

  • Download / Hapus file satu per satu (tombol di setiap entry).
  • Hapus semua file sekaligus.
  • Hapus folder: cukup lihat nama folder di daftar, lalu klik Hapus Folder – akan muncul input untuk memasukkan nama folder (karena folder tidak bisa diklik hapus langsung, tapi kamu bisa salin dari daftar).
  • Hapus repository secara permanen.

Catatan: Untuk menghapus repo, token harus memiliki akses admin ke repo tersebut (biasanya pemilik).
