📄 Single File Upload (Baru)

1. Pilih folder tujuan. 2. Pilih file yang ada di folder itu (otomatis muncul). 3. Klik Muat File untuk mengisi kode ke editor. 4. Edit kode, gunakan pencarian jika perlu. 5. Klik Upload File. Cocok untuk update cepat file yang sudah ada.

📦 Upload ZIP (dengan opsi hapus root)

Kompres folder proyek menjadi ZIP. Centang Hapus folder root jika ZIP hanya berisi satu folder (misal folder proyek berisi file), agar isinya langsung masuk ke repo tanpa folder tersebut.

✏️ Editor File (Full)

Pilih file dari daftar, muat, edit, lalu simpan. Mirip dengan tab Single, tapi ini langsung menampilkan daftar seluruh file.

📂 File & Folder Browser

Jelajah semua file/folder, download, hapus, hapus semua, atau hapus repo.

✏️ Rename (Interaktif)

Pilih folder dulu, kemudian pilih file yang ingin direname (atau biarkan file kosong jika ingin rename folder itu sendiri). Nama baru otomatis terisi, tinggal edit.
