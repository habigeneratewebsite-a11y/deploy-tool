📄 Single File Upload

Unggah satu file ke folder tertentu. Pilih folder dari dropdown (otomatis terisi setelah Muat Struktur). Masukkan nama file, tempel kode, lalu klik Upload File. Cocok untuk deploy cepat dari chat AI.

📦 Upload ZIP (Banyak File)

Kompres folder proyek menjadi ZIP, lalu unggah. Semua file di dalam ZIP akan diekstrak dan diupload dengan struktur folder yang sama. Pastikan ZIP tidak mengandung folder root yang tidak diinginkan.

✏️ Editor File

Pilih file yang sudah ada dari dropdown, klik Muat File, lalu edit isinya. Setelah selesai, klik Simpan & Upload untuk menyimpan perubahan langsung ke repo. Fitur ini memudahkan perbaikan cepat tanpa buka laptop.

📂 File & Folder Browser

Menampilkan seluruh isi repo: folder dan file. Di sini kamu bisa:

  • Download file (⬇️)
  • Hapus file satu per satu (🗑️)
  • Pilih folder untuk dihapus (klik "Pilih untuk hapus" di folder, lalu klik tombol Hapus Folder)
  • Hapus semua file sekaligus
  • Hapus seluruh repository (dengan konfirmasi dan pengecekan hak admin)
✏️ Rename File / Folder

Ganti nama file atau folder. Pilih item dari dropdown (file atau folder), masukkan path baru yang diinginkan, lalu klik Rename. Untuk folder, seluruh isinya akan dipindahkan ke lokasi baru. Fitur ini bekerja dengan membuat file baru di path baru dan menghapus yang lama.

🌍 Siapa yang Bisa Memakai Tool Ini?

Tool ini bisa dipakai oleh siapa saja yang memiliki:

  • Akun GitHub (gratis)
  • Personal Access Token dengan izin repo (untuk baca/tulis) dan delete_repo (untuk hapus repo)
  • Repository target milik sendiri (atau akses kolaborator)

Tidak perlu menginstall apa pun. Cukup buka halaman tool ini di browser HP atau desktop, masukkan kredensial, dan semua fitur siap digunakan. Tool ini sepenuhnya berjalan di sisi klien (browser), tidak ada data yang disimpan di server eksternal selain GitHub API.
