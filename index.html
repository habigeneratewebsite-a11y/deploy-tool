📘 Panduan Lengkap HABI STUDIO CODING .ZIP

📄 Single File Upload

1. Pilih folder tujuan. 2. Pilih file yang ada di folder itu (otomatis muncul). 3. Klik Muat File untuk mengisi kode ke editor. 4. Edit kode, gunakan pencarian jika perlu. 5. Klik Upload File. Cocok untuk update cepat file yang sudah ada.

📦 Upload ZIP (dengan opsi hapus root)

Kompres folder proyek menjadi ZIP. Centang Hapus folder root jika ZIP hanya berisi satu folder (misal folder proyek berisi file), agar isinya langsung masuk ke repo tanpa folder tersebut.

✏️ Editor File

Pilih file dari daftar, muat, edit, lalu simpan. Mirip dengan tab Single, tapi ini langsung menampilkan daftar seluruh file.

📂 File & Folder Browser

Jelajah semua file/folder, download, hapus, hapus semua, atau hapus repo.

✏️ Rename (Interaktif)

Pilih folder dulu, kemudian pilih file yang ingin direname (atau biarkan file kosong jika ingin rename folder itu sendiri). Nama baru otomatis terisi, tinggal edit.

➕ Buat Repositori Baru

Isi nama repositori, pilih visibilitas, centang jika ingin README otomatis. Klik Buat Repositori. Jika berhasil, link repo akan muncul dan bisa dicopy.

📋 Daftar Repo & Hapus Massal

Tab Daftar Repo menampilkan seluruh repositori milik akun GitHub-mu. Kamu bisa mencentang satu per satu atau gunakan Pilih Semua untuk memilih semua repo (kecuali deploy-tool yang dilindungi). Setelah memilih, klik Hapus Repositori Terpilih untuk menghapusnya. Riwayat penghapusan tercatat di bawah.

⚡ Mode Anti-Lag

Toggle Mode Anti-Lag (default ON) akan menghentikan animasi partikel latar belakang sehingga website terasa lebih ringan dan responsif, terutama di HP. Kamu bisa menonaktifkannya jika ingin efek penuh.

👥 Multi‑Akun & Token Panel

Klik Akun untuk menyimpan, memuat, menghapus profil GitHub. Token aktif bisa dilihat/disalin. Gunakan Simpan untuk menyimpan akun saat ini. Data credential tidak akan hilang meskipun keluar dari browser.
