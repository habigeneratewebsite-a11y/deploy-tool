📘 Cara Menggunakan HABI STUDIO CODING .ZIP

🚀 Deploy Single File

Tempel kode HTML/CSS/JS langsung dari chat AI. Tool akan otomatis menambahkan struktur HTML & metadata SEO jika belum lengkap. Klik Deploy Single File → file index.html langsung terupload ke repo.

📦 Upload ZIP (Banyak File)

Buat ZIP dari HP (pakai ZArchiver/RAR) berisi seluruh folder project kamu. Pastikan struktur foldernya rapi (misal app/api/...). Pilih file ZIP, lalu klik Upload ZIP & Deploy. Semua file akan diekstrak dan diupload dengan struktur yang sama ke GitHub.

✏️ Editor Single File

Masukkan nama file (misal api/route.js), lalu tulis/edit kode di editor. Gunakan tombol Cek Error untuk validasi sintaks sebelum upload. Fitur pencarian dan ganti teks tersedia. Klik Simpan & Upload, akan muncul pop-up konfirmasi "HABI STUDIO NOTE" untuk memastikan kamu yakin ingin mengupload.

🕒 Jam Digital & Waktu Azan

Jam otomatis tampil dengan detik, hari, dan tanggal. Jadwal azan diambil dari API Kemenag untuk Jember, Jawa Timur (koordinat: -8.1845, 113.6681). Update otomatis setiap hari.

⚠️ Cek Error / Validasi

Tombol Cek Error akan menganalisa kode berdasarkan ekstensi file: .js dicek sintaks JavaScript, .json dicek format JSON, .html dicek struktur HTML. Jika ada masalah, muncul pesan error. Fitur ini membantu mencegah deploy kode yang bermasalah.
