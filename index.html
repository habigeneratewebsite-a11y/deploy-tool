📘 Panduan Lengkap HABI STUDIO CODING .ZIP

📄 Single: Cari file/folder di input pencarian, klik hasil untuk memuat kode ke editor, edit jika perlu, lalu klik Upload File. Gunakan fitur ⚡ Revisi AI untuk mengganti potongan kode dengan cerdas dan aman.

📦 ZIP: Upload file ZIP berisi proyek, otomatis diekstrak dan diupload ke repositori dengan struktur yang sama. Centang Hapus folder root jika ZIP hanya berisi satu folder utama.

✏️ Buat Baru: Buat file baru langsung dari tool tanpa perlu membuka GitHub. Masukkan path lengkap (contoh: repo/app/page.tsx), tulis kode di kolom konten, lalu klik Simpan. Folder akan otomatis terstruktur. Nama repo bisa ditulis di awal path atau tidak (akan menggunakan repo yang sedang aktif).

📂 Files: Jelajah isi repositori, cari file/folder, download, hapus file, hapus folder, hapus semua file, atau hapus repository. Gunakan tombol Muat Struktur untuk memuat daftar file. Baru! Klik 📥 Download Repository ZIP untuk mengunduh seluruh isi repositori sebagai file ZIP dengan progress bar. Nama file dipertahankan asli (termasuk yang diawali titik seperti .gitignore).

✏️ Rename: Cari file atau folder, pilih dari hasil, nama baru otomatis terisi, edit jika perlu, lalu klik Rename untuk memindahkan/rename.

➕ Buat Repo: Buat repositori GitHub baru langsung dari tool. Isi nama, pilih visibilitas, dan tambahkan README jika perlu.

📋 Daftar: Lihat semua repositori milik akun GitHub-mu. Centang repo yang ingin dihapus (repo deploy-tool dilindungi dan tidak bisa dicentang). Klik Hapus Terpilih untuk menghapus. Riwayat penghapusan tercatat di bawah.

💬 Chat to ZIP: Tempelkan teks dari chat AI yang menggunakan penanda 📁 untuk setiap file. Tool akan memproses dan membuat file ZIP yang siap diunduh. Sangat berguna untuk mengubah percakapan AI langsung menjadi struktur proyek.

👥 Akun: Kelola banyak akun GitHub. Setiap akun menampilkan nama profil, username, repo, dan token (sebagian). Gunakan tombol ✅ untuk memilih akun, ✏️ untuk mengedit, dan 🗑️ untuk menghapus. Klik ➕ Tambah Akun untuk menambah akun baru (form modern, bukan prompt). Saat menambah atau mengedit akun, otomatis akan beralih ke akun tersebut. Detail akun bisa dicopy dengan klik 📋. Akun yang sedang aktif ditandai dengan badge ✅ di daftar. Kredensial tetap tersimpan meskipun browser direfresh.

🔑 Token: Klik tombol 🔑 untuk panduan lengkap cara mendapatkan token GitHub dengan izin repo dan delete_repo.

🎨 Tema: Klik 🌓 di pojok kanan atas untuk beralih antara tema gelap dan terang.

🖼️ Logo: Upload file logo.png (ukuran 200x55px) ke root repositori untuk menampilkan logo kustom. Jika tidak ada, area logo akan kosong. Logo memiliki efek shadow dinamis yang aktif 20 detik setiap 1 menit.
